# FischleLab_KarthikEswara_ribo0seq_repeats

## Preparing gtf

**getRepeatDAta.R** - Nonredunant genome annotations for repeats were obtained fom [Dfam database version 3.5](https://www.dfam.org/releases/Dfam_3.5/annotations/ce10/) and lifted over to the ce11 version of the genome. Repeat loci were given unique names by appending "_rpt#" to the repeat family name, and a gtf was constructed with the same annotation given gene, transcript and exon types. This was then concatenated with canonical gene annotation gtf downloaded from [Wormbase (WS298 version)](https://downloads.wormbase.org/releases/WS298/species/c_elegans/PRJNA13758/).

**getRepeatAnnotation.R** - Repeat classification was downloaded with [FamDB tools](https://github.com/Dfam-consortium/FamDB) for Dfam version 4.0, and then merged with Dfam 3.5 annotations using the `getRepeatAnnotation.R`script.

## Downloading RNAseq from ENA

**makeENAlist.R** - makes a file with list of European Nucleotide Archive (ENA) accession numbers for use with nf-core/fetchngs pipeline

**nf_fetchNGS_submit.sh** - downloads RNAseq samples from ENA with the nf-core/fetchngs pipeline

## Alignment with nf-core/rnaseq

**makeSampleSheet.R** - prepares sample sheet and contrast matrix required for running nf-core/rnaseq and differential abundance pipelines

**nf_repeats_rnaseq_submit.sh** - uses the nf-core/rnaseq pipeline to align reads to C. elegans genome/transcriptome and Dfam repeats, using a specially contructed gtf with all canonical genes and repeats.


## Differntial expression with nf-core/differentialabundance for canonical genes

**filterCountsMatrix.R** - before alignment the counts matrix and gene_lengths matrix produced by nf-core/rnaseq pipeline was filtered to remove all rows containing dfam repeats (for details regarding repeat analysis see below). In addition, 42 noncoding RNA genes with extremely high counts were removed. The genes were from the ribosomal RNA clusters on chromosomes I and V, as well as signal recognition particle RNA (srpr).

**nf_differentialabundance.sh** - slurm script to perform differential gene expression analysis of canonical C. elegans genes. Note: script is designed to output results into a directory named with parameters used. This "runName" needs to be pasted into subsequent scripts to point them to the data.

## Post processing for canonical genes

**postProcessing.R** - script adds gene names and locations to results tables and merges them into a single file with the contrast name as "group". Needs "runName" generated by nf_diffentialabundance.sh.

## Final plots for canonical genes

**upreguledGenesOnArms.R** - boxplots, violin plots and heatmaps of expression of genes on autosomal arms. Needs "runName" generated by nf_diffentialabundance.sh.

**integrationWithChIP.R** - euler plot of autosomal arm genes and their overlap with ChIPseq peaks of HPL-2, LIN-61 and H3K9me2. Boxplot and violin plot of gene expression of those autosomal arm genes that overlap chipseq peaks of all three types. Also produces lists of gene names of significantly upregulated genes on autosomal arms (in general, or those overlapping all three chipseq peak types) for running GO analysis; and bed files of significantly upregulated genes on autosomal arms for deeptools. Needs "runName" generated by nf_diffentialabundance.sh.

**deeptools_sigGenes_v_ChIP.sh** - creates heatmaps with deeptools of HPL-2 LIN-61 and H3K9me2 ChIPseq signal (from GSE271919) over significantly upregulated genes on autosomal arms. Needs "runName" generated by nf_diffentialabundance.sh.

**functions_finalFigures.R** - some functions used by plotting scripts.

**pca.R** - generates a pca plot for variation stabilising transformed counts. Needs "runName" generated by nf_diffentialabundance.sh.

**getCountTablesForGEO.R** - script to extract raw counts of gene expression for the different datasets to upload to GEO. 

## Differential exression of repeat famlies using Telescope

Repeats were quantified with the [Telescope](https://github.com/mlbendall/telescope) (single locus resolution of Transposable ELEment expression) software [PMID: 31568525](https://pubmed.ncbi.nlm.nih.gov/31568525/).

> "Bendall, Matthew L., Miguel de Mulder, Luis Pedro Iñiguez, Aarón Lecanda-Sánchez, Marcos Pérez-Losada, Mario A. Ostrowski, R. Brad Jones, et al. 2019. Telescope: Characterization of the Retrotranscriptome by Accurate Estimation of Transposable Element Expression. PLoS Computational Biology 15 (9): e1006453."

note: --attribute flag gives error with transcript_id, so gene_ids need to be unique names if you want to get locus-level counts. 

**makeBamlist.R** - takes a list of bam files created by the nf-core/rnaseq pipeline and creates the appropriate input for Telescope.

**runTelescope.sh** - sorts bam files by name and uses telescope singularity container to quantify repeats

## post processing of telescope data

**indexUpdatedBam.sh** - sorts updated bam files generated by Telescope by position and indexes them so they can be viewed in IGV.

**getRepeatAnnotation.R** - merges Dfam4.0 repeat classification with Dfam3.5 family data.

**DErptFamilies.R** - Collects counts of different tables generated by Telescope and aggregates them to get family-level counts. Then performs differential expression analysis with DESeq2 exporting a results table.

## Final plots of telescope data

**plotRepeatFamilies.R** - generates bar plots for repeat family expression from the DESeq2 results table.

**plotRepeatFamilies_heatmap.R** - generates heatmap for LFC of gene expression of repeat families from DESeq2 results table.
